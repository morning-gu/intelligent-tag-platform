# 开放评测（open-eval）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为平台补上第七个前端模块「开放评测」——镜像闭环评测的 open 干跑运行器（库内命中集合准确率 + 新词/命中二值评审通过率 + gt 标定评审员），DB 零写入。

**Architecture:** 干跑 `OpenTagProducer`（settings 参数透传实现 per-run 副本：文本模态 + 审计重定向进 run 目录）→ 产出二分（库内命中/新词）→ 评审模型二值评审（摘录必核）→ 纯标准库指标装配（`open_ranking.py`）→ 报告七件套落 `data/eval/open/<run_id>/`。服务层 `OpenEvalService` 与 `ClosedEvalService` 互查活跃 run（busy_probe 无锁读，防锁序死锁）。

**Tech Stack:** FastAPI + SQLAlchemy（只读）+ 纯标准库指标 + React/antd（零新依赖）+ vitest/pytest。

**Spec:** `docs/superpowers/specs/2026-11-22-open-eval-design.md`（用户已批准 2026-11-22；计划从 spec 立论，执行者两个都读）

## Review Focus

1. **评审响应畸形家族**（围栏 / 单对象 / 别名键 / 模型漏判 id——147.3 前科四起）：漏判 id 不判 pass 也不判 fail（`pass=None`，排除出分母、计 `review_missing`）；整片全漏 / 两连解析失败 → 该片评审失败。→ Task 3 测试钉死。
2. **双服务并发起跑与锁序**：closed 活跃时 open 起跑 409、反之亦然；busy_probe 无锁读保证不死锁。→ Task 4 测试钉死。
3. **交集外命中混入分子分母**（白给 precision / 冤枉 recall）：`hit_in_flags=False` 的条目只计数不进准确率/标定。→ Task 2 测试钉死。
4. **评审摘录未命中原文仍 pass**（空口通过）：quote 经 `_quote_ok` 核不中 → 记 fail 且 reason 注明。→ Task 3 测试钉死。
5. **modalities 含 video 的起跑**（v1 无帧接线，会静默读 MovieNet）：起跑校验 400 拒绝并说明。→ Task 4 测试钉死（Task 6 端点层复验）。

### Task 2: open_ranking.py 指标装配（纯标准库）

**Files:**
- Create: `src/tagplatform/services/eval/open_ranking.py`
- Test: `tests/test_eval_open_ranking.py`（新文件）

**Interfaces:**
- Consumes: `services/eval/ranking.py` 的 `precision 分数族原语`（`macro_average` / `bootstrap_ci` / `ndcg_at_k`）
- Produces（Task 5 报告组装按此消费）：
  - `DEFAULT_THETAS: tuple[float, ...] = (0.2, 0.4, 0.6, 0.8)`；`DEFAULT_THETA_HEADLINE: float = 0.4`（三处展示位统一取格目标，前端镜像）
  - `@dataclass(frozen=True) OpenSample(label: str, hit_ids: tuple[str, ...], hit_in_flags: tuple[bool, ...], intersection: dict[str, float], hit_pass: tuple[bool | None, ...] | None, new_pass: tuple[bool | None, ...] | None)`——`hit_ids` 全部命中（含交集外）保持产出序；`hit_in_flags` 对齐（True=tag_id ∈ 该片交集）；`hit_pass`/`new_pass` 对齐（条目 None=模型漏判；整体 None=该片评审失败）
  - `@dataclass ThetaRow(theta, n_valid, accuracy, accuracy_ci, accuracy_random, accuracy_prior, coverage, n_calibrated, agreement, agreement_ci, fp_rate, fn_rate)`（None≠0：无有效片 → None）
  - `@dataclass OpenReport(n_total, n_ok, n_failed, n_review_failed, n_invalid, no_gt, theta_rows: list[ThetaRow], ndcg_macro, ndcg_ci, new_pass_macro, new_pass_micro, new_pass_n, hit_pass_macro, hit_pass_micro, hit_pass_n, review_missing, new_ratio_macro, warnings: list[str])`
  - `evaluate_open(samples: list[OpenSample], gt: dict[str, dict[str, float]], thetas: Sequence[float] = DEFAULT_THETAS) -> OpenReport`

口径（spec §5，全部写进模块 docstring）：
- 准确率@θ = |命中∩(gt≥θ)| / |交集内命中|，逐片后宏平均；`n_valid` 只计交集内命中非空的 ok 片；随机基线 = r/n 解析解逐片宏平均（r=交集内 gt≥θ 数，n=交集标签数）；先验基线 = 按 `gt` **全影片**标签均值降序的固定排序取前 |交集内命中| 条的 precision@θ（逐片宏平均）
- nDCG = 交集内命中按产出序、gt 连续增益、`ndcg_at_k(k=len(hit_in))`，全列表不截断
- 覆盖率@θ = |交集内命中且 gt≥θ| / |交集内 gt≥θ 总数|
- 通过率（宏为主微为辅）：新词 = new_pass 非空片上 pass 数/总数（漏判条目排除出分母分子）；命中同理（分母含交集外命中）；`n_review_failed` 片排除
- 标定（θ 上展开，仅交集内命中、评审成功的片）：TP=pass∧gt≥θ / FP=pass∧gt<θ / FN=fail∧gt≥θ / TN；一致率=(TP+TN)/n、假阳率=FP/n、假阴率=FN/n，宏平均
- `review_missing` = 漏判条目总数（None≠0，报告单列）；`new_ratio_macro` = 新词/总产出宏平均（0 总产出片排除）
